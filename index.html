GWS CLI

GWS CLI is a personal, single-user command-line tool that accesses my own Google Workspace account (Drive, Docs, Sheets and related services) through the Google APIs.

Privacy Policy

This application is used only by its owner. It does not collect, share, sell or transfer any user data to third parties. OAuth tokens and Google data stay on the owner's own server and are used only to perform the actions the owner requests. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Terms of Service

This tool is provided as is, for personal use by its owner only.
